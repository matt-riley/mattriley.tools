# Catalog Showcase

A static showcase of Matt Riley's published work and configuration.

## Domains

**Homebrew Tool**:
A CLI tool distributed via a custom Homebrew tap formula.

**Neovim Plugin**:
A Vim/Neovim plugin published as a GitHub repository with `.nvim` in the name.

**Public Template**:
A public GitHub repository marked as a template for scaffolding new projects.

## Visual language

Under Pressure presents three interactive print studies on warm paper. The featured plates use wood engraving, overprint and contour etching to illustrate specific tool behaviour. All published works enter the index from the generated catalogue. GSAP choreographs the sheet turns and yields to reduced-motion preferences.
